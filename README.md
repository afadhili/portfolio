# AIFadh — Portfolio

A modern, bento-style personal portfolio for **Ahmad Isnainil Fadhili (AIFadh)**: frontend + backend developer and university student in Indonesia, studying network security and AI.

**Live:** [afadhili.vercel.app](https://afadhili.vercel.app)

> Both sides of the stack. Curiosity meets craft.

---

## Features

- **Bento grid layout** with mixed tile sizes, responsive from desktop to mobile
- **Dark and light mode**, with no flash of the wrong theme on load
- **Animated UI**: staggered entrances, scroll reveal, hover effects, and a marquee, all respecting `prefers-reduced-motion`
- **Live GitHub data**: public repos, stars, language breakdown, and recent activity
- **Project showcase** with custom artwork mockups per project, tags, repo stats, and optional live demo links
- **Archive view** for all repositories, with pagination
- **Writing section** for notes, articles, and case studies
- **Quick search / command palette** (`Ctrl/Cmd + K`)
- **Accessible by default**: semantic HTML, keyboard navigation, visible focus rings, ARIA labels
- **SEO-ready**: meta tags, Open Graph, and Twitter cards
